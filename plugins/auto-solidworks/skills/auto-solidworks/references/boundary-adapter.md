# Boundary 创建与保存定义合同

本文的原始离线基线只有核心、模拟端口、编译和 MCP 试运行证据。2026-10-03 原生诊断发现 `InsertNetBlend2` 可同步新增有效 `NetBlend` 而返回空指针；当前执行器以完整调用前后库存绑定唯一新增特征，继续严格核对来源、控制和保存回执。当前版本的正式原生验收仍在进行，诊断结果不替代完整门槛。

创建前清空选择库存，按两个方向的首／尾／中间角色选曲线。实际选择必须同时符合数量、标记、顺序和完整来源曲线身份；相同标记但选错实体也会在调用工厂前拒绝。方向 1 支持 2..128 条曲线，方向 2 支持 0..128 条曲线。来源必须为已声明的原生草图曲线或螺旋线。

调用 `InsertNetBlend2` 创建曲面体，不把空工厂结果替换为 Fill。工厂参数与每条曲线、两个方向控制通过同一核心端口执行。`SetNetBlendCurveData` 与 `SetNetBlendDirectionData` 返回 Feature 而非 bool，不能把辅助返回值当最终成功凭据；必须读取最终定义。

工厂前后均读取完整原生 Boundary 特征库存。即使返回空指针，也只有新增唯一未抑制、无错误及警告的 `NetBlend` 才能进入原有定义复核；已有特征、多个新增特征、不完整或重复库存、原生命令遗留和返回旧指针均拒绝。发现特征不是最终验收成功，仍须证明原来源身份、顺序、端条件、原生体有效性及保存重开。

定义复核包含原生曲线族完整库存、顺序和身份，None／NormalToProfile 条件、原生切向长度与方向、可用的统一切向控制、拔模参数、全局影响和可用的 `TrimByD1`。None 不读取无效的切向长度；多方向不读取单方向专用 `GetTangentApplyToAll`；没有第二方向时不读取不可用的 `TrimByD1`。接口无 `TrimByD2`，不编造第二方向裁剪读回。

法向控制目前沿用工厂的原生默认切向长度参数 1，并要求定义保留该值；本轮没有引入用户可指定的任意长度。该原生控制含义和几何影响尚需以后真实样例确认。

完整 Feature／Sketch 包装变化可以映射到同一来源。只有原草图确实只有一个非构造段、段自身和所属草图身份均匹配时，单个 SketchSegment 才可以代表完整曲线；多段草图中的单段不能冒充全部来源。保存回执保留来源绑定和控制，重开路径复核持久身份等价和曲线顺序；Boundary 的曲线族顺序影响结果，不能像无序集合那样交换后通过。

官方 `SetNetBlendDirectionData` 文字列举的 InfluenceType 与本机 `swBoundaryBossCurveInfluenceType_e`／官方 Boundary 示例不同：前者列举 Global=0，后者为 GlobalInfluence=32。本轮保留本机枚举与示例的 32 路径，并以定义读回 32 为验收条件；该分歧没有通过原生实验解决。

离线样例包含跨平面弯曲 2x2 网络、显式三维点空间网络、错位角点、重合端点和缺失 IR 依赖。四角合同只核对模型空间端点，不证明中间交叉、连接器方向、实际插值、无自相交或 G1/G2 连续性。真实 Boundary 失败记录仍保持失败，其他 B01–B06 剩余工作仍开放。

最终定义捕获使用操作 ID 的已捕获原生持久引用，核对原生特征 ID、实际名称和原生持久身份；同名来源不会按显示名称重新绑定。法向端条件仍必须通过保存重开严格读回，不接受仅创建期控制。
