# 源语义与拓扑变更历史

当前源码 `.28.validation` 已接入有界生产持久历史：在独立矩形基体副本上，受控改厚度后执行一条右上纵边的恒定圆角。已有当前原生创建、保存重开、完整回执重验以及新客户端公开检查证据。一般拓扑历史和特征输入历史仍未实现；B03 的范围限制继续公开。

`GeometryRef.semantic` 将语义键、根实体 token、来源特征持久身份、原始配置和允许的变更操作与原有模型／源修订及源事实绑定。旧 `GeometryRef` 冻结签名路线保留，但它不提供语义拓扑命名。

观察端口提供完整模型修订库存、每版独立源几何定义、操作身份和 Unchanged／Modified／Generated／Split／Merged／Deleted 关系。解析器核对起止模型／源／文档修订和配置，从根实体沿连续历史查后继，以当前源几何筛选，再核对本次真实库存。分裂后仍有多个满足源定义的后继必须报告歧义；删除后不能选坐标相同的另一特征实体。未知、缺失、矛盾或不完整历史不能回退到旧签名／最近实体。

源几何定义应由源参数和设计意图独立推导，不能复制待选实体的测量值。历史数据必须来自执行／观察端口；公共 MCP 输入只接受源引用合同，不接受调用者提交一份“成功历史”当作原生证据。未变修订仍使用原生只读库存；支持的两步编辑使用生产端捕获的完整原生身份映射，不推测失效的 Tracking ID。

回执包含完整历史、摘要和引用指纹。修复及边处理验收使用回执前重新执行解析和身份核对；一个 `Resolved` 字段不能自证成功。语义回执生成的选择携带 `require_persistent_identity:true`，原生端必须恢复并核对同一实体及来源范围，不能退化为坐标后备。未保存的内存模型不能以磁盘文件哈希证明修订身份。引用与历史摘要使用类型化 JSON 和数值负零规范化，字符串及非零数值保持不变。旧分隔字符串指纹的回执需从新源码重新生成，不能当作本版证据复用。

`cad_create_model_plan` 的 `draft.box_edge_history`（或 `cad_build_model` 的 IR `box_edge_history`）声明宽、长、初始厚度及三个驱动维度原生名、基体名和改厚度／圆角操作 ID。只支持单配置、按毫米修改厚度、关闭切向传播的单边恒定圆角，以及全新输出；恢复、覆盖、配置设计意图和其他操作链均拒绝。根引用在新 target 修改前产生，其 DocumentId 来自实际副本路径。前端目标从宽／长／新厚度／半径推导为 `(宽/2-R, 长/2, 厚度-R)`，而非复制测量候选。生产端逐项读回驱动尺寸，保存每步原生文件、全部边库存及来源身份，要求改尺寸身份双射和单边圆角四后继因果关系成立。

本地持久库位于 `%LOCALAPPDATA%/AutoSolidWorks/semantic-history/v1`。检查点是实际保存文档的不可变字节副本；认证记录绑定根引用、每个检查点 SHA 和完整历史摘要，并以本地 MAC 拒绝被修改的外部 JSON。检查接口重新核查全部检查点和当前真实库存。MAC 不防同一 Windows 用户对密钥或进程的完全控制；它的职责是阻止普通 MCP 输入和未认证记录冒充生产历史。检查点、模型和记录共同构成恢复材料，不能只携带根引用。

构建结果的 `semantic_history` 证据提供根引用文件、生产记录文件和终点修订元数据。之后可将根引用传入 `cad_inspect_model.geometryReferences`；省略修订字段时由可信记录提供当前源／文档修订，显式给错仍拒绝。必须检查嵌套 `geometry_ref_resolutions[].status` 和完整 `semantic_receipt`；外层 `success:true` 仅表示模型读取成功。

公开检查重建后的 dirty 标记保护仍保留。解析零件的保存修订认证比较重建前、重建后及干净只读重开的完整体／面／边持久身份双射、全部来源、驱动参数／方程／特征／配置状态、整件几何和修剪参数采样；不保存源文件或清除 dirty 标记。支持平面／圆柱面和直线／圆边，总库存上限 4096；未知自由曲面、非有限数据、漏库存、变参数或多义身份均拒绝。此认证是有界解析状态一致性证明，不是通用形状等价或 G2 证明。

现有边界：只支持最终 B-Rep 面／边的语义合同，特征输入 B-Rep 历史未实现；通用布尔、分裂、合并、任意配置或曲面编辑的原生生产历史尚未提供。共有边保留全部实际来源，不能强行选一个特征。核心能表达更多关系，但核心／模拟端口通过不能扩大原生生产范围。

研究依据：[FreeCAD 拓扑命名算法](https://github.com/realthunder/FreeCAD_assembly3/wiki/Topological-Naming-Algorithm)提供输入到生成／修改实体的历史思路；[SolidWorks Tracking IDs](https://help.solidworks.com/2023/english/api/sldworksapiprogguide/Overview/Tracking_IDs.htm)说明该机制的重建／会话生命周期限制。研究不表示插件已拥有对应内核能力。
