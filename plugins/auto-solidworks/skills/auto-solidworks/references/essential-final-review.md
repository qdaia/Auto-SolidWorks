# 必要收尾验收（essential-final-review-1）

本次优化针对代理收尾编排，运行库、建模合同和原生检查不变。默认只完成影响交付判断的检查；不把输出文件存在当成验收通过。

## 普通零件默认流程

1. 首次计划一次声明必要尺寸、孔轴/数量、相交/开缝处局部检查。源图确有通盲要求时保留适用的连接性证据。避免在成功建模后才临时增加第二套验收。
2. build成功后，使用返回的artifact_path与artifact_sha256读取一份必要摘要：必须确认最终保存重开/重建、模型SHA256一致、Check3故障0、建模与保存后声明检查均通过，并保留geometry_status、parametric_status和欠定义草图名单。
3. 一次查看等轴测及能覆盖源图关键特征的必要视图合成图。普通两投影零件通常为isometric/front/left；其他图纸按真实视图选择。每个源视图中的独有特征都需有对应覆盖。另有背面盲孔、沉孔入口、隐藏腔、剖面或来源反证时加入必要视图/剖切；不能固定“三图”代替判断。
4. 没有新问题时立即交付模型、简短验收结论和计时。完整回执在本地保留，不逐页读全部成功evidence、所有点测量或所有面边。常规收尾目标30至60秒，不是保证值或硬截止；失败仍明确失败。

生成五张标准预览的原生行为继续保留。这里减少的是代理实际重复阅读/复查：具有对称、冗余且无新增源特征的视图可不再次逐张查看，需要记录覆盖理由。源图原始页面/非空细节仍按识图流程检查。工程图PDF交付仍看所有页面。

## 本地摘要与合成图

从插件根目录运行，所有参数使用本次工具返回值；输出目录必须是未使用的绝对路径：

~~~powershell
python scripts/summarize-final-review.py --receipt <artifact_path> --receipt-sha256 <artifact_sha256> --source <原图绝对路径> --source-sha256 <source_manifest.source_sha256> --views isometric front left --reason "<与源图特征对应的覆盖理由>" --output-directory <新的绝对目录>
~~~

文字建模可同时省略source与source-sha256。需要Pillow，仅用于将原生预览等比例缩小并排版，不裁剪，不修改模型。如果Pillow不可用，直接看现有必要原生图片，不为拼图下载依赖或修复环境。其他必需身份/验收字段缺失或失败时，不能把工具故障当成验收通过。

助手必须实际查看essential-views.png才能给出视觉复查结论；工具始终返回visual_status=pending_actual_image_review。助手查看后只声明所看视图的源特征覆盖，不宣布全图/BREP等价。输出保留所有所选原图路径与哈希、完整回执路径与哈希、最终模型及报告身份、失败/参数化状态。输出目录已有内容时拒绝覆盖。

辅助程序只读取插件已经完成的原生回执，不连接SolidWorks，不触发build/inspect，不修改源图/模型，也不替代插件的机器验收。

## 何时才追加检查

- 模型、配置、源图/来源修订或声明检查发生变化。
- build回执未能证明保存重开、实体有效性或某个必要要求；成功项不重查。
- 必要视图中出现遗漏、裁边、孔朝向或拓扑疑点；只补该局部。
- 用户明确要求改参稳定性、完整库存、STEP/工程图或装配验收。

没有上述触发时，不另跑cad_inspect_model；不默认追加数百个等距采样点，不做编辑试算，不重读全部成功回执。不能删掉失败检查后宣布通过，不能把TrimmedAxisAndDiameter改说成完整孔壁/通盲认证。强制的声明检查和源解释门禁继续保留。

## 性能与证据

工具processing_seconds仅统计本地摘要校验与拼图，不包括模型构建、助手视觉审查或思考。它不能作为建模总时间或完整收尾时间。未经完整工作流实测，不宣称已实现30至60秒收尾或某个提速百分比。
