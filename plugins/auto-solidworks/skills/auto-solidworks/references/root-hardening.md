This is a local development revision. Current capabilities come from the bundled `capability-manifest.json`, embedded in the MCP executable; version drift is rejected and package creation checks generated skill/document summaries. Do not extrapolate earlier native fixture passes to changed source.

Text input normalizes explicit mm/cm/m/in lengths, including Chinese aliases. A trailing tuple unit qualifies that tuple; unqualified lengths outside it remain mm. All deterministic templates audit named numeric consumption and remaining vocabulary. A plain extrusion may request all edges filleted with one explicit radius smaller than half its smallest envelope dimension. Ambiguous edge scope, unsupported features, extra dimensions and malformed units fail with no executable plan. Use typed drafts for richer designs. Supported rounded boxes and cylinders retain a source-derived rounded-volume expectation rather than the original sharp volume.

Boundary uses the SOLIDWORKS 2025 `InsertNetBlend2` first/end/interior selection-role contract, checks the actual selected inventory, and reads the created feature's two curve families. These checks prevent wrong or partial selections from becoming success. The previous bowed 2×2 fixture failed with legacy 1/2 marks. The corrected adapter passed managed tests; native construction/save/reopen was not rerun because opening SolidWorks was prohibited. Do not substitute Fill or relax source geometry when Boundary fails.

`verification.whole_model_checks` declares independent complete visible and hidden solid/sheet body counts, face/edge/open-edge counts, a full face partition by Plane/Cylinder/Cone/Sphere/Torus/BSpline/Other and optional area/volume. `require_whole_model_inventory:true` cannot be satisfied by finite probes alone. Every enumeration/adjacency failure is unverifiable, and native body Check3 faults reject verification. Declare expected values from the source; never copy executor measurements back into the expectation. These are global structural checks, not an exact positional BREP equivalence or G1/G2 proof. Finite probes remain useful for attachment and local dimensions.

Drawing layout accepts paper dimensions in mm, first/third-angle projection and up to seven standard orientations including Front. View positions/scales and schedule capacity are derived from sheet geometry. Additional schedule pages use Parameters_2, Parameters_3, etc.; every page is included in the PDF and every entry's identity/value/unit/page is read back from saved native notes. There is no 44-parameter limit. Native visual collision assessment remains a separate acceptance step. No manufacturing completeness is inferred from a parameter schedule.

Native requests have a bounded pipe response deadline (default 300000 ms); direct CLI requests use the same deadline and receipt mechanism. Typed plans configure `execution_deadline.deadline_milliseconds` (1..3600000) and `pause_acknowledgement_milliseconds` (1..5000). A timeout or broken connection after submission is failure with `outcome_unknown`, never success. The server refuses to queue another native request while one remains active; a shared file lease also excludes other executor processes. `cad_execution_status(requestId)` and `cad_pause_execution(requestId)` use a separate control connection without starting SolidWorks. Receipts persist under LocalAppData/AutoSolidWorks/executor-receipts, overridable with CAD_EXECUTOR_RECEIPTS_DIR. Never blindly replay an unknown mutation. A prior-process unfinished receipt remains unknown; an unfinished native lease blocks automatic continuation. Synchronous COM cannot be forcibly aborted safely by CancellationToken; cancellation takes effect at the next execution boundary and no promise of killing a hung SolidWorks operation is made.
