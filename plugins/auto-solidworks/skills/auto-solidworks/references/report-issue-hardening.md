# 报告问题修复合同：来源解释、预执行检查、验收与回执

此版本为 26.10.12 本地修复候选。构建与离线测试不是原生 CAD 验收；现有 26.10.11 安装及三个最终模型保持独立。不会自动改变图纸尺寸、切换方向、扩大引用搜索范围或把失败预期改成实测结果。

## 来源解释先于数值建模

新图纸任务设置 `drawing_context.require_interpretation_review=true`。`interpretation_reviews` 每个关键特征一条，包含 `feature_id`、`selected_hypothesis_id`、`dimension_datum_derivation`、`hypotheses`。每个假设有唯一 `id`、`description`、`observations`；观测有特征声明的 `view_id`、归一化原图 `bounds`、`observation` 和 `contradicts`。

必须先实际检查原图再写观测。所选假设在各声明视图均须有支持且无反证，其他假设必须有源反证才能排除。所选假设有反证报 `SOURCE_INTERPRETATION_CONFLICT`；缺关键特征复核报 `SOURCE_INTERPRETATION_REQUIRED`。不要填模板文字假装独立看图，不能以模型数值自洽代替来源解释。合同不能发现未声明的图像反证，也不能认证观察者身份独立。

Ø20平顶/中心孔：分别列出轮廓与孔解释，核对等轴图实心顶面、立视图及6-Ø15数量。局部R20/整个圆截面：核对连续宽带顶面与侧壁，先固定截面与90尺寸基准，不增加未经多视图证实的20直段。原图无剖面等残留限制必须保留。

旧调用未提供严格标志时保留兼容，但返回 `SOURCE_INTERPRETATION_LEGACY`，结果显示 `legacy_not_required`。不能据此声称新图纸任务完成来源解释验收。已声明的矛盾即使在旧合同中也会拒绝。

## 方向、引用和净距

编译自动提示显式 Hole 框架的法向、起始点、reverse及切除方向。对于显式 ReferenceAxis 与 Frame 的可解析旋转，提供源轮廓代表点按轴正向右手约定的 start/mid/end 轨迹。轨迹帮助发现返弯向内等错误，不认证原生 API 选轴方向；仍需原生点/法向与来源形状核对。

对显式框架的圆柱拉伸和同向孔计算标称径向净距：外径/2−孔心到轴距离−孔径/2。精确内切报告 `HOLE_ZERO_THICKNESS_RISK`，它是有限几何风险提示，尚未核对轴向交集、后续布尔和当前真实实体边界。不能宣称唯一内核根因，不能自行调整尺寸。非等距倒角返回相邻面次序提示；仍须从源图保留横/竖要求并检查倒角面偏移点/法向，当前版本没有自动交换原生两个距离。

原生引用失败保留完整 `query_json`、选择范围、候选/匹配数量、最近五项以及候选诊断截断标志。最近项只用于解释失败；不能自动扩大到全部体或随意选择最近边。

## 尺寸、约束和授权偏差

自动定义圆已有驱动圆径。额外对同一圆添加手工半径/直径会在编译时返回 `SKETCH_DUPLICATE_DRIVING_DIMENSION`。原生状态4返回 `SKETCH_OVER_CONSTRAINED`，指示撤回重复尺寸/固定关系；其他失败保留状态值。缺原生尺寸返回所请求路径及同一特征可枚举的实际活动尺寸名称，不按数值近似猜选，抑制特征不能通过。

明确授权的偏差仍绑定执行值，并补 `nominal_value`、`deviation_reason`、`deviation_authorization`、Derived状态及推导。例如标称32.5、执行32.45，说明差−0.05和授权来源。验证和操作都绑定32.45，原图文字仍保留R32.5。编译器检查字段齐全，不能证明授权文本真实；代理必须使用会话中真实授权。0.05剩余壁厚不代表制造或强度认可。

## 完整孔壁与裁剪圆柱

`CylinderGroupCheck.coverage` 默认 `CompleteWall`，继续要求正长度、轴起止、直径、方向、完整侧壁面积和数量。锥面裁剪/相交墙不可通过放大公差转换成完整墙。

明确选择 `TrimmedAxisAndDiameter` 时 `length_mm` 必须为0；只检查可测圆柱的解析轴线、直径、内外向和数量。回执 `scope=trimmed_cylinder_axes_diameters_count`，不认证轴向长度、周向完整性、孔底、贯通性或整个模型。此模式不允许绑定 `length_mm` 作为来源长度证明。补独立孔壁与孔底的有限点/法向/面积，孔数量可另绑定原生阵列整数。需要通孔证明时另用专用连接性工具，不用圆柱模式代替。

计数期望须非负整数，公差必须大于0且小于0.5，例如6±0.01。完整圆柱长度和一般实测公差的非法0值继续拒绝。完整模型库存仍需所有可见/隐藏体、面/唯一拓扑边及曲面分区，必要时独立面积/体积与正公差；有限点不等于全库存。周期参数缝不能凭参数区间重复增加边数，不允许看到实测8边后直接把源预期16改成8来通过。

无法测量返回 `SOURCE_REQUIREMENT_UNVERIFIABLE` / `SAVED_REQUIREMENT_UNVERIFIABLE`；实测不同仍是 MISMATCH。每个检查保留状态，两类同时存在时顶层优先报告MISMATCH，子项保留无法测量证据。切除null返回 `CUT_EXTRUDE_NULL` 及方向/终止/深度/起始偏移参数；没有唯一原因时明确说明，不能把方向、交集和零厚度误合并成已证明根因。

## 回执、工程图和视觉范围

内容地址回执使用按哈希命名的跨进程互斥锁，先在同一目录写唯一pending临时文件并Flush，再原子改名。已有文件须字节一致才复用，不覆盖损坏内容。中断的临时文件保留诊断，不直接删除。回执保存失败时仍保留request_id和状态，先查执行状态，不能重放修改；历史丢失的精确耗时不会因此恢复，未知仍为未知。

工程图参数表 `schedule_row_height_mm` 只接受7～20，默认9；错误明确字段、输入值和范围，不偷偷修正。预览证据只表示图片文件写出，`visual_coverage` 明确为未验证；不能由字节非空推导无裁边。应实际查看每个视图，补完整图纸/PDF并逐页核对。当前未证明通用预览裁边自动修复，源图与最终模型视觉等价也没有通用认证。
