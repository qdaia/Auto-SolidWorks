# 默认中文输出

本地版本：`0.6.0+zh.20261001.3`。默认语言：`zh-CN`。

## 生成内容

- 自然语言建模的模型名称、设计树特征名称与验收名称默认中文；类型化草稿省略名称时自动生成中文名称。
- 43 种原生特征均有中文名称，包括基准面／轴、孔、圆角／倒角、阵列、旋转、放样／扫描、钣金、焊件、多实体和曲面操作。
- 插件创建的辅助基准面、钻孔／沉孔草图、移动特征和装饰螺纹使用中文后缀。
- 装配体零部件默认使用“零部件_1”等中文名称，操作引用仍按独立 ID 解析。命名前选择目标零部件，关闭名称跟随文件名设置；原生名称未保留时明确失败。
- 工程图采用微软雅黑，页名为“视图”“参数表”“参数表_2”等；标准视图使用“主视图”“俯视图”“左视图”等中文名称。
- 工程图标题、投影说明、比例、零件／装配体类型、参数标签、毫米／度／个、已标注／仅参数表备注默认中文。
- 工具说明、插件提示、验证结果、诊断和错误解释默认中文。MCP SDK 的通用工具异常提示也转换为中文。
- Gordon 曲面工作器的生成标签、报告说明和本地配置提示使用中文。该路径没有因中文化重新获得原生曲面或 G1／G2 认证。

## 保留原值

用户明确指定的名称、文件路径和图纸原始内容按原样保留。已有模型不自动重命名。导出旧英文模型时，工程图使用中文参数标签，结构化结果保留原生尺寸路径，避免破坏驱动尺寸和模型引用。

工具名、JSON 字段、操作 ID、错误码、坐标系／工件 ID、单位枚举、SolidWorks API 名、字体名、文件格式、螺纹／材料标准等技术标识保持原值。中文显示与接口标识分开处理。

SolidWorks 启用“零部件名称跟随文件名”时，会在后续重开时覆盖保存的自定义名称。为保留中文零部件名，成功创建装配体后将该应用设置保持关闭；创建失败时恢复原设置。这项设置是可逆的，源文件名和引用路径不变。

## 验证范围

离线回归覆盖名称生成、序列化、引用、第一角／第三角布置、分页、错误分类、单位、命名前置条件和用户设置恢复。公开 MCP 检查覆盖中文工具说明、能力清单、输入错误、英文输入生成中文名称和离线执行。

原生验证使用独立新文件：中文圆盘保存与设计树读回、中文 SLDDRW／PDF 保存重开、中文参数表与视图提取，以及使用英文文件名源零件创建的中文零部件装配体和自动工程图。核对源零件哈希，并渲染 PDF 页面检查中文字体与版面。

详细报告保留在源码仓库的 `artifacts/chinese-default-20261001/`。复杂模型与原生连续性的旧证据仍属于此前版本，不能用本轮文字验收替代。
