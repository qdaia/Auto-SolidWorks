# Auto SolidWorks `26.10.11` 更新说明

发布日期：2026 年 10 月 11 日。版本号采用 `YY.MM.DD`，按年/月/日排列。

**简体中文** | [English](release-26.10.11.en.md)

## 更新内容

- **减少重复 token 输入**：整合此前的精简工具目录、按需合同、计划句柄、默认摘要与分页结果，避免每次向模型展开大型 schema 或重复返回完整计划和 IR。
- **完整输入复用**：新增 `cad_store_model_input`，完整图纸上下文及草案保存到本机；遗漏复查和编译可通过 `drawingContextId` / `draftId` 引用。
- **原子增量修改**：通过 `baseInputId` 与 JSON Patch 的 add / replace / remove / test 修正局部内容，生成新不可变输入；失败保留原输入。
- **保留验证要求**：复用前核对来源、内容、编译器和恢复身份；服务端恢复完整输入后继续原有编译、覆盖与几何验证。完整最终回执可复用，新增要求、文件变化与 STEP 导出仍需独立检查。
- **统一安装版本**：优化版并入 Auto SolidWorks `26.10.11`，默认提供 16 个工具，完整配置提供 21 个工具，保留专用检查入口。

## token 输入负担的实测变化

下表测量的是去空白 JSON 请求／返回字符数。前三项来自此前 `26.10.07` → `26.10.07.1` 的同输入接口对照，本版继承其机制；新增工具后目录长度会变化。

| 场景 | 优化前字符数 | 优化后字符数 | 减少 |
|---|---:|---:|---:|
| 上次优化：默认工具目录 | 406,144 | 10,683 | 97.37% |
| 上次优化：编译结果 | 5,836 | 1,331 | 77.19% |
| 上次优化：建模调用参数 | 3,528 | 96 | 97.28% |
| 输入复用：含首次完整上传、3 次复查、编译及一次修正重编译的工作流 | 589,879 | 125,346 | 78.75% |
| 空心轴：同一 R5 引用修正及重编译，按 JSON-RPC 请求字符数计 | 1,920,316 | 1,383 | 99.928% |

这些结果说明重复文本输入显著减少，可减少模型生成与传输大型 JSON 的工作。**实际计费 token 未记录，不能将字符降幅直接写成同等 token 或费用节省。** 首次完整输入仍需上传，图像、上下文、系统提示和工具返回也会影响总 token。

同一会话的拱形支座对照墙钟从 9 分 19.2 秒降至 3 分 15.4 秒；两版均通过 13 项声明检查、原生保存重开及独立 STEP 检查。该单次观察包含预热、原版排错及同会话经验影响，不作为稳定提速比例。
