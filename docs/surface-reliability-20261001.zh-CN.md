# 本地复杂曲面可靠性升级

版本：0.6.0+surface.20261001.1。仅本地开发、打包与安装，无远程发布。

修复重新编译产生随机 plan_id 后错误拒绝检查点的问题：前缀指纹忽略请求 ID 和输出路径，保留源身份、已执行操作及参数。实际安装版已验证：错误顶部圆角查询返回 ReferenceResolution 和附近候选，修正后复用 R4 检查点并成功完成剩余操作；参数或源版本改变仍会拒绝复用。

本轮补齐球面半径、球心、裁剪面采样与材料外法向联合校验；鼠标 R41 顶面和 SR8 凹槽可通过原生文件和 STEP 读回核实，错误半径、球心和凹面法向必须失败。检查结果提供球面参数、持久引用和凹凸分类。

修改特征的实体选择从生成面或受影响面确定所属实体，避免 Draft 无生成面时无法定位实体；保持歧义拒绝，禁止全模型实体替代。选择失败提供候选数量、匹配数量、选择范围以及最多五个附近候选，帮助修改查询而不自动吸附。

检查点文件支持 SolidWorks 写入句柄下的只读哈希计算，保留身份核验；每次保存重开均记录 readback.json。鼠标交集后的体积在重开前后相差约 0.00655 mm³，超过原严格门槛，该检查点仍被拒绝。R4/R1 圆角后的检查点通过严格校验，可以用于恢复。没有放宽几何容差。
