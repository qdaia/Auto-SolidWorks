# 本地 source-workflow-2 验证范围

版本 26.10.18-local.1，基于 26.10.17 发布源码，本轮不对外发布。

默认新图纸工作流使用四项来源门禁。已声明消费者自动引用尺寸事实，矛盾保留为错误；失败编译也返回可修订的 prepared_draft_id。聚合预检提前报告来源、几何、参数化、验收和恢复问题。拉伸位置独立声明基准、方向和区间；可计算的分离连接提前拒绝，未知情况不冒充通过。

圆头耳板、半圆环和四分之一圆环采用带驱动尺寸的轮廓；孔位具备必要驱动关系。阶段编译与后台原生执行可重叠，实际 CAD 操作串行；自动检查点选择验证来源、前缀和文件身份。局部投影使用固定毫米坐标和显式覆盖范围，不做自动拟合。交付分别记录原生、声明几何、参数化、来源投影和人工视觉声明。

验证包含 22 组托管回归、49 项专项回归、130 项公开 MCP 检查、5 份原始练习51草案的编译重放。受控耳板、半圆环、四分之一圆环完成原生创建；最终运行时对三者重新打开并执行 6 个改变几何的参数编辑与恢复探针，全部通过。受控四孔板验证了阶段执行、两步检查点复用、局部投影正反例和分层交付状态。

包内 current-native-evidence.json 绑定最终运行库、模型和检查回执 SHA-256。证据只覆盖所列任务、SolidWorks 2025 修订 33.0.0 和声明检查，不证明任意图纸一次成功或完整制造图/BREP/GD&T 等价。未重新建模练习51，未开展隔离历史的盲测或可比的端到端速度测试。识图仍由 AI 完成，门禁验证证据结构与一致性，不能保证识图语义全部正确。阶段重叠试验重叠的是已知输入的编译，不能称为实测识图并行提速。
