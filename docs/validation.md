# 0.5.1 公开发布验证

此页记录 GitHub 首次发布的验证范围，不将历史 CAD 样例结果合并为本次重新实测结果。

## 本地执行的检查

- Windows / .NET SDK 9.0.316：MCP、公共库和 SolidWorks 执行器从公开源码构建成功。
- 插件 manifest 与技能结构验证通过。
- 8 项非 CAD 烟雾检查通过：8 工具集合、默认执行参数、文字计划与导出路径、可选 dry-run、typed 草图/凸台/切除、错误几何拒绝、合成图片页面/线条读取、dry-run 不创建原生模型。
- 7 项尺寸绑定检查通过：英寸换算、数值冲突、角度绑到长度、缺失操作、Unknown 尺寸、无说明 Derived 尺寸、能力目录匹配。
- Windows ZIP 解压、逐文件 SHA-256 核对和安装脚本通过；在隔离的 Codex 配置目录中注册插件成功，安装缓存 72 个文件与准备好的插件逐一一致，并从该安装缓存再次通过全部 8 项烟雾检查。
- 发布副本与原开发目录的全部 C# 源文件逐一比较，内容一致；公开发布调整集中在构建路径、安装/打包脚本、文档和测试材料。

## 验证边界

本次公开打包没有重新运行完整 SolidWorks 原生建模矩阵，也没有重新证明真实图纸与 CAD 模型等价。上述检查不表示 OCR 尺寸准确、所有 SolidWorks 版本兼容或所有原生特征组合均已通过。

GitHub Actions 只构建 MCP 和公共托管库、检查 Python 语法与目录/链接；托管 runner 没有 SolidWorks，不能代替原生执行器、COM 建模或几何验收。

原开发目录的私人图纸、CAD 文件和安装历史未包含在本仓库中。公开的 61 个合成原生测试定义可以用于后续本机复测；焊件型材和部分装配测试具有明确的本机依赖，见[开发说明](development.md)。
