# 0.5.4 公开发布验证

本页区分本次公开发布源码检查与此前同版开发插件的参考件验证。开发安装版本为 `0.5.4+codex.20260909121021`，公开版本为 `0.5.4`。

## 本次发布检查

- 从公开发布目录重新构建 MCP、托管库与 SolidWorks 原生执行器。
- 52 项核心回归、23 项图纸回归和 7 项尺寸绑定契约检查通过。图纸回归中 5 项不依赖私有数据，其余检查使用本机参考 PDF。
- Windows ZIP 包含中英文 README、文档与既有公开案例，提供逐文件 SHA-256 清单及压缩包校验文件；不分发 SolidWorks interop DLL 或 PDB。
- 发布包在隔离 Codex 配置中执行安装，并从安装缓存检查 9 个工具、默认执行参数、文字/typed 计划、dry-run、无效几何拒绝和合成图片读取。安装缓存按文件哈希核对。
- C# 源文件与已验证开发目录一致；公开工程保留可配置的 SolidWorks interop 路径。修复 Windows PowerShell 下安装目录末尾反斜杠造成构建参数引用失效的问题。

## 同版开发插件的本机参考件验证

14 个用户确认的原生参考零件导出 14 份 SLDDRW、14 份 PDF，共 28 页。81 项安装后参考件检查、14 份 PDF 读取和 28 页边界检查通过。导出后重新打开原生工程图检查两张纸页、第一角法、四视图和对应模型引用；源模型哈希保留。

尺寸读取从旧实现的 123 条原始记录（106 个唯一参数）改为 206 个唯一参数：188 个长度、16 个角度、2 个计数。188 个参数插入视图，18 个仅列入参数表。PDF 数字候选从 329 条变为 201 条，这反映文字分组变化，不能解释为准确率。

该原生参考件验证在同版开发安装上完成；公开打包过程重新构建并检查托管逻辑与安装，不重复执行完整原生参考件导出。私有参考 CAD、PDF 和本机报告不上传。

## 验证边界

模型导出的工程图不是独立原始图纸，这些结果不证明 14 个零件的盲重建成功。未重跑全部历史特征及装配矩阵；几何、参数和文件检查不等于任意图纸尺寸、公差或拓扑全面验收。

工程图导出当前支持已保存零件、A3 纸页、英文/中文标准视图和最多 44 个源参数。欠定义草图仍可能缺少必要定位信息；复杂图纸可能有较长构造线、密集标注或仅在参数表中列出的尺寸，需要进一步整理。OCR 冲突仍交给读图解释，不能直接作为建模事实。

GitHub Actions 构建托管项目，检查仓库结构，运行 52 项核心及 5 项不依赖私有 PDF 的图纸检查。托管 runner 没有 SolidWorks，不能替代 COM 建模或原生几何验证。公开保留原有 61 个合成零件测试定义和新增局部几何/倒角脚本，原生测试具有本机依赖，见[开发说明](development.md)。
