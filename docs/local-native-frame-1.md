# 26.10.19-local.1 本地修复说明

针对2026-10-19同图独立实测失败。旧版创建任意框架时CreatePlaneFixed2的UseGlobal=true使局部轴改为全局投影轴，约束和原点仍按声明框架解释。改为false并在加约束前验证实际草图变换。移体特征可能没有新生成面，改用受影响面/原生特征归属查找后续旋转目标。合并拉伸增加分离实体时立即停止，保留上一检查点。

提前拒绝配方中不存在的原生尺寸名，并列出命名合同。提前拒绝关键源尺寸绑定于未被特征消费的独立构造草图。圆柱检查支持radius_mm=diameter_mm/2的只读源绑定，始终验证与原始来源数值一致，修改半径不会静默同步直径。

旧版半圆环和耳板孔切除已原生复现失败；候选版相同输入通过。最终版三类旋转/偏置受控模型完成独立包络、体积、质心、孔轴、完整声明库存、保存重开及参数编辑恢复；移动/复制后旋转另有受控原生回归。22组托管回归通过，其中来源工作流54项。包内当前原生证据索引按最终运行库哈希绑定。

原始首版整件草案在修复框架后已生成1个实体、总高56mm；实际圆头/孔检查通过，但原草案的未消费辅助尺寸使最终参数化验收失败。后续编译门禁已将该问题提前。该整件仍不是合格交付，不声称完整图纸、视觉、BREP或GD&T等价，不是盲测，也没有端到端提速或一次成功率结论。只在本机安装，不公开发布。
