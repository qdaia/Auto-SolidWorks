# Auto SolidWorks 1025

发布日期：2026-10-25。同步本机最新版 26.10.24-vision.9 的源码与运行时，公开版本号为 **1025**。

## 本次内容

- 默认四步：识图、尺寸绑定、编译、建模；新输入使用 source-four-stage-2，显式旧合同保持兼容。
- 原图几何候选、批量尺寸绑定、局部绑定诊断；图像语义仍由 AI 实际看图决定。
- 源尺寸表达式支持角度 Sin/Cos，独立正视圆支持页面横纵拉伸校准；不把像素距离当模型尺寸。
- 增加源角度射线与实际草图正X轴的带符号方向检查，拦截已经复现的耳板前后镜像错误；执行前再次检查编译结果。
- 保留参数归属、源端点、单位、原生重建、保存读回和实体有效性检查。

## 验证范围

发布执行源码/合同检查、托管回归、公开MCP接口、安装包内容/哈希核验及本机新会话身份验证。具体结果见[发布验证说明](release-validation-1025.md)。

本次1025发布不重新运行原生CAD建模，native_execution_for_release=false。vision.9此前通过的定点原生修复属于该版本的历史证据，不转写为1025原生认证。方向检查覆盖源角度表达式驱动的草图X轴；主视图基和视图标签仍需识图复核，不认证全图/BREP/GD&T等价或通用识图准确率。

## 安装

下载Windows ZIP及对应SHA-256文件，核对摘要，解压后运行 install.ps1。SolidWorks Interop来自使用者本机安装，不随发布包分发。所有建模输出默认在本机保存。
