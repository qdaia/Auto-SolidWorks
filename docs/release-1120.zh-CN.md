# Auto SolidWorks 1120 · Windows x64 统一插件包

**本次发布仅做了离线测试，未做真实 SolidWorks 回归验收。** 发布测试没有启动 SolidWorks，也没有验证真实 COM 连接、原生建模、保存重开、几何精度、装配或工程图输出。此前版本的实机记录仅适用于当时的构建。

## 下载与安装

下载 `auto-solidworks-1120-windows-x64.zip`，解压到长期保留的目录，在解压根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

一个 ZIP 内含一份公共 MCP 和 11 个原生执行器构建，覆盖 2018–2026 九个年度版本。安装器读取本机两份 Interop 的版本，在同一年度内选择满足版本要求的最高构建。安装多套 SolidWorks 时，可通过 `-SolidWorksInteropDir` 指定目标安装目录。使用 `-SkipCodex` 可只准备文件，验证选择结果。成功后会显示实际选择的构建和安装目录。完整安装后请打开新的 Codex 聊天。

## 本次修复

- 针对健康检查超时，改进冷启动等待和请求状态处理。已退出执行器遗留的健康检查租约可使用安装目录中的 `scripts\recover-health-lease.ps1` 核对并归档。使用说明见安装目录的 `docs\installation.md`。
- 旧版执行器使用相应年度的质量属性和截面接口。备用模板按目标年度查找；构建缓存同时区分 Interop 文件内容和程序集版本。
- 修复与 [Issue #1](https://github.com/qdaia/Auto-SolidWorks/issues/1) 相关。2018 SP5 的真实运行结果仍待反馈。

## 已知限制

2027 缺少已验证的 35.x 编译引用，本包覆盖至 2026。2018 的同心配合旋转锁定读回仍有限制；2018 SP2 之前的构建缺少高精度射线接口；边界曲面流程中依赖原生界面命令的读回仍限于原有的 2025 SP0 路径。
