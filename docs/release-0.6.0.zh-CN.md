# Auto SolidWorks 0.6.0 更新公告

发布日期：2026-09-25。

0.6.0 将当前最终优化版整理为正式编号发布。相对 0.5.5-rc4，建模与验证算法保持一致，更新运行时和插件版本标识、发布入口，并补充最新实测证据。版本号不代表任意复杂图纸或长期连续运行已经获得全面认证。

## 相对 0.5.4 的累计更新

- 公共工具由 9 个扩展为 15 个，增加图纸覆盖复查、原生投影/剖面捕获和旋转件、孔组、圆角倒角的限定范围验证。
- 图纸解释保留来源事实、关键尺寸绑定、原图细节区域及遗漏候选核对；OCR 继续作为辅助，模型仍负责视觉解释。
- 加强几何引用、方向测量、通盲连接检查、修复前后差异检查和受约束修复；保留未受影响要求的验证。
- 保留可验证前段的恢复机制、原生保存关闭重开、实际驱动尺寸修改与还原检查。
- 提供默认关闭的分阶段计时，保持检查覆盖，未使用减少检查换取速度。

## 本次 0.6.0 发布验证

重新构建后的 428 项源码回归、9 项公共接口检查通过；15 个公共工具和运行时版本一致。安装包通过逐文件哈希、隔离安装及安装后检查，本机安装缓存的 77 个文件与安装源一致。新安装的 0.6.0 实际执行合成带孔板建模、保存重开、投影和剖面检查，并通过 STEP 导出后回读及原生尺寸 10→11→10 mm 修改还原，源模型文件哈希保持不变。详见[验证记录](validation.md)。这些合成检查不代替独立工程图验收。

## 已有实测证据与适用范围

2026-09-24 对功能相同的候选执行了 22 个不同阶段的性能矩阵：新进程、热运行、局部修改各 n=5，两种工作负载共 30 个正式样本，排除 3 个预热样本，570 项断言通过。共 31 个工作负载/阶段组合、93 个测量单元。去除本机路径的原始时间和调用数见 [性能数据 CSV](performance-0.6.0.csv)。这些记录来自版本更新前的候选；0.6.0 的重新构建、安装及原生烟雾结果另在本次 Release 中列出。

主链是合成带孔板，复查修复链是实际原生圆角修复与孔保形样例。新进程不等于系统冷启动；局部修改完整重建；嵌套耗时不能相加；n=5 的 p95 仅用于本机诊断。没有与 0.5.4 的同条件加速对照。

已开封图纸中的销轴诊断回放通过保存重开、8 项声明几何检查、14 条来源/参考投影线段匹配及长度修改还原检查。该结果只证明声明的名义几何范围，不计入独立保留集成绩；用户图纸、参考 CAD 和私有测试产物不随公开版本分发。

## 已知边界

- 七例独立工程图试验因执行中断与隔离连续性证据缺失记为无效，完整独立验收未完成，不发布通过率。
- COM 激活、单独预览、装配、工程图导出和 STEP 导入未独立分段计时；未完成长期连续运行或全 API 性能认证。
- 真实 IR 1.1–1.3 存档兼容性尚未实测；增强 OCR 与查看器选择映射保持关闭。
- 螺纹使用名义孔与装饰螺纹表达，不生成实际螺旋牙形；不认证完整 GD&T、粗糙度或实际材料/热处理性能。

## 安装
