# Auto SolidWorks 0.5.5-rc4 更新公告

这是基于本机已验收 rc4 的预发布更新。重点是图纸遗漏复查、保存模型的几何验证、受约束修复与恢复可靠性。独立工程图保留集验收和完整性能矩阵尚未完成，因此不将本版标记为完整产品验收通过。

## 本次新增与增强

- 公共 MCP 工具从 9 个增加到 15 个：新增 `cad_review_drawing_coverage`、`cad_capture_projection`、`cad_capture_section`、`cad_verify_revolved_family`、`cad_verify_hole_group`、`cad_verify_edge_treatment`。
- 图纸输入增加独立候选清单、重叠区域及残余图形复查；未解决的必要内容阻止完整通过。OCR 仍为候选，智能体负责结合原图解释，未宣称自动保证完整召回。
- 增加有身份约束的几何引用、定向测量、限定孔腔通盲验证、原生投影和平面剖面采集，以及来源要求覆盖汇总。
- 台阶轴、孔组、沉头孔、沉孔、盲孔和装饰螺纹信息具有更完整的限定范围原生验证；不生成或认证物理螺旋牙。
- 修复链绑定来源版本、模型和计划身份、修复范围、完整差异与检查证据；拒绝合成/过期凭据，以及修圆角时顺带改变无关孔径等范围外修改。
- 补强客户端断线、暂停边界、重连、损坏或过期检查点拒绝，以及有效前缀续跑。数值负零指纹规范化保留字符串与非零值差异；旧凭据可能需要重新实际执行生成。
- 新增默认关闭的内部计时。设置绝对路径环境变量 `AUTO_SOLIDWORKS_TRACE_DIRECTORY` 后记录阶段、进程和父子关系；计时日志写入失败不改变原操作结果，但该轮计时证据无效。

## 验证范围

发布前本机 rc4 的验证包括：429 项自动检查、203 项原生检查、安装缓存公共 MCP 18/18、实际桌面入口 8/8，以及真实历史 IR 1.4 输出路径迁移后的原生兼容 6/6。203 项原生检查包括几何检查36、孔组12、边处理19、旋转件14、恢复10、轴向孔19、孔型72、真实修复21。

这些是开发样例、故障注入及限定真实执行路径的结果，不能换算成任意工程图成功率。发布 ZIP 保留本机已验收 rc4 的运行 DLL/EXE 字节；公开源码另行构建并运行回归，安装包另做隔离安装、文件哈希与 15 工具烟雾检查。PDB 和 SolidWorks 专有 interop DLL 不在 ZIP 中；安装器从使用者自己的 SolidWorks 安装准备 interop。

三组性能开发样例各 n=5，另排除一次预热。原生构建中位数为新 MCP/执行器进程14.578秒、暖进程13.692秒、局部尺寸修改完整重建13.437秒。新进程组保留 SolidWorks/OS 缓存；父子阶段耗时重叠；没有无计时对照或与0.5.4同条件对照，不声称加速比。

## 尚未完成

- 独立原始工程图保留集挑战、生成端与评测端访问隔离及完整评测协议。
- observation/coverage/diff/repair 的同条件三组性能矩阵，以及部分未独立计时阶段。
- 真实 IR 1.1–1.3 历史存档迁移；IR1.4通过不代表这些版本已经实测。
- 可选工程 OCR 对照和 Viewer 选面映射仍保持关闭；现有 Tesseract 候选提取是既有能力。开放模型仅完成公开来源预检后关闭这一范围。

0.5.4 已有的建模、装配、局部几何检查、工程图导出和基本检查点能力保留。原生特征类别仍为36类；工具数量增加不等于整体能力提升66.7%。
